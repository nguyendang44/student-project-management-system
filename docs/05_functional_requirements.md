\# 5. Functional Requirements



| ID | Requirement | Description |

|---|---|---|

| FR-01 | Authentication | Người dùng đăng nhập hệ thống. |

| FR-02 | Authorization | Hệ thống phân quyền theo Student, Lecturer và Admin. |

| FR-03 | Student Management | Quản lý thông tin sinh viên. |

| FR-04 | Lecturer Management | Quản lý thông tin giảng viên và số lượng sinh viên tối đa. |

| FR-05 | Lecturer Capacity | Theo dõi số lượng hiện tại, số lượng tối đa và số chỗ còn lại của giảng viên. |

| FR-06 | Topic Management | Quản lý đề tài và trạng thái đề tài. |

| FR-07 | Topic Registration | Sinh viên đăng ký đề tài có sẵn. |

| FR-08 | Lecturer Request | Sinh viên gửi yêu cầu giảng viên hướng dẫn. |

| FR-09 | Request Approval | Giảng viên chấp nhận hoặc từ chối yêu cầu và nhập lý do khi từ chối. |

| FR-10 | Capacity Validation | Hệ thống kiểm tra giới hạn giảng viên ở phía server trước khi chấp nhận đăng ký. |

| FR-11 | Project Management | Quản lý dự án sau khi đề tài và giảng viên được xác nhận. |

| FR-12 | Milestone Management | Tạo, cập nhật và quản lý milestone. |

| FR-13 | Progress Update | Sinh viên cập nhật tiến độ thực hiện. |

| FR-14 | Evaluation | Giảng viên đánh giá kết quả milestone. |

| FR-15 | GitHub Integration | Liên kết repository GitHub với dự án. |

| FR-16 | AI Code Analysis | Phân tích source code và tạo báo cáo hỗ trợ. |

| FR-17 | Notification | Gửi thông báo về các sự kiện quan trọng. |

| FR-18 | Deadline Checking | Tự động kiểm tra deadline theo lịch. |

| FR-19 | Automatic Status Update | Tự động cập nhật trạng thái dựa trên tiến độ và deadline. |

| FR-20 | Dashboard | Hiển thị thông tin tổng quan về dự án và tiến độ. |

| FR-21 | Reporting | Cung cấp thống kê và báo cáo. |
