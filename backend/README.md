# Backend API skeleton

ASP.NET Core 10 layered solution with 501 endpoint placeholders. .NET SDK required for `dotnet restore`/`dotnet build`; no SQL connection required to start scaffold. `/health` is implemented. JWT parameters are configured; no login token issuance exists. Schema draft in `StudentProjects.Infrastructure/Persistence/StudentProjectsDbContext.cs`, without migrations. Full implementation requires the Week 3 ERD and Week 4 API contracts.
